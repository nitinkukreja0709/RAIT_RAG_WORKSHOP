# RAG Workshop — From a Simple Pipeline to Evaluated, Reranked Retrieval

Workshop notebooks on building and evaluating retrieval-augmented generation (RAG) systems.

| Notebook | Topic |
|---|---|
| `1.Simple_RAG.ipynb` | End-to-end RAG: load, split, embed, retrieve, generate |
| `2. Data_Loading_and_chunking.ipynb` | Loading PDFs, CSV, Excel, HTML and text; chunking strategies |
| `3. Embedding_and_Vectordatabase.ipynb` | Embeddings and vector databases |
| `Evaluation_and_Reranking.ipynb` | Baseline RAG → evaluation → improvements such as reranking |
| `6..RAGAS.ipynb` | Measuring faithfulness, answer relevance and context quality with RAGAS |

Slides: `rag_introduction_slides.pdf`, `demo_ppt.pptx`. Sample data files are included for the loading exercises.

## Setup
Provide your own API keys via environment variables (`GOOGLE_API_KEY`, `OPENAI_API_KEY`) — none are stored in this repo.
